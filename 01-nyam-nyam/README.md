# 01 · 냠냠걱정 (nyam-nyam)

> hachan-lab 1일차. 걱정을 적으면 고양이가 먹어치우고 맛을 평가한다.

## 실행

```powershell
cd C:\sein\hachan-lab\01-nyam-nyam
npm install
copy .env.example .env   # ANTHROPIC_API_KEY 입력 (비워두면 목업 대사로 동작)
npm run dev              # http://localhost:5173
```

## 구조

```
index.html        화면 뼈대 (선택 화면 / 먹이기 화면)
src/main.js       흐름: 선택 → 먹이기 → 애니메이션 → 맛 평가 → 배부름
src/cats.js       고양이 3마리 설정 + SVG 그림
src/style.css     스타일
api/_taste.js     맛 평가 로직, 성격 프롬프트, 무거운 내용 분기
api/feed.js       배포용 서버리스 함수 (POST /api/feed)
vite.config.js    개발 서버에서 /api/feed 를 같은 로직으로 연결
```

API 키는 서버 쪽(`api/`)에서만 쓴다. 브라우저 코드에 넣지 말 것.

## 기획

### 핵심 경험 (10초)
1. 고양이를 고른다
2. 걱정을 적고 "먹이기"
3. 글자가 한 글자씩 고양이 입으로 빨려 들어간다
4. 맛 평가 한마디
5. 걱정은 사라지고 다시 볼 수 없다 (저장 안 함)

### 고양이

| | 까망 | 치즈 | 백설 |
|---|---|---|---|
| 성격 | 츤데레 | 먹보 | 미식가 |
| 말투 | 짧고 시큰둥한 반말 | 신나는 반말, 감탄사 | 정중한 평론가 존댓말 |
| 배부름 | 3개 | 7개 | 5개 |
| 배부르면 | "됐어. 가." | "배불러... 쿨쿨..." | "오늘 코스는 여기까지입니다." |

배부름은 고양이별로 따로, 하루 단위로 초기화.

### 맛

| 걱정 | 맛 |
|---|---|
| 돈 | 짠맛 |
| 인간관계 | 쓴맛 |
| 미래·진로 | 싱거움 |
| 지난 일 | 눅눅함 |
| 사소한 것 | 과자맛 |
| 긴장(발표·시험) | 매운맛 |
| 그 외 | 신맛 |

원칙: 고양이는 조언·위로하지 않고 맛만 평가한다.

### 무거운 내용
자해·자살 등은 장난치지 않는다. 배부름·식단표에 세지 않고,
"옆에 있을게" 톤의 대사와 자살예방상담전화 109 안내를 띄운다.
(키워드 1차 확인 + AI의 `heavy` 판정 2중)

### 저장하는 것
`localStorage` 에 오늘 날짜, 고양이별 먹은 횟수, 맛 집계만. 걱정 원문은 저장도 로그도 하지 않는다.

## 배포
Vercel에 폴더를 연결하고 환경변수 `ANTHROPIC_API_KEY` 를 등록하면 `api/feed.js` 가 그대로 동작한다.

호출 횟수 제한은 `api/_limit.js` 에 있다. 기본은 IP당 1분에 10번 (`NYAM_RATE_PER_MIN`).
환경변수가 없으면 메모리로 세는데, 서버리스는 인스턴스마다 따로 세므로 공개 배포 전에는
Upstash Redis를 만들어 `UPSTASH_REDIS_REST_URL`, `UPSTASH_REDIS_REST_TOKEN` 을 등록할 것.
Anthropic 콘솔에서 월 사용 한도도 함께 걸어두면 안전하다.
